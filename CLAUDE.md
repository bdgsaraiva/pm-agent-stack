# pm-agent-stack — rules for any Claude session in this repo

This is Bernardo's **personal** build of a PM agent stack (Steps 1–3 of the blueprint in `docs/architecture.md`). It runs on public data only.

## Hard rules
- **No fund data here.** Never write the fund's positions, sizes, P&L, order history, broker research or proprietary notes into this repo, a prompt, a note or a log — not even as a summary. `portfolio/` and `journal/` hold dummy or public-idea files only. The corporate build lives elsewhere.
- **Numbers come from code.** Agents quote figures only from `briefs/<date>/facts.md` (or a DuckDB query over `data/`, the journal, or a critic card), with the source link. No figures from memory or the web in a note. Every written output is run through `python -m pmstack audit` before it is published.
- **Facts vs inference.** Label interpretation. No trade instructions. Size suggestions come only from `pmstack/sizing.py`, in paper risk units, as advice; decisions stay with the PM.
- **Log every agent run** with `python -m pmstack log --step <name> --fields '<json>'`.
- **Licences.** `pmstack/adapters/yahoo.py` is unofficial and personal-use only; do not port it. Never add Bloomberg-derived data to this repo.
- **Literature first.** Before building any agent, review the most cited papers, the Atlas investor cards and the specialist books; write `docs/research/<agent>.md` (finding → what it changes → source) and build from it.
- **Quant standards.** Alerts are not signals. Anything promoted to a signal goes through the quant-research gate (alpha vs beta, out-of-sample, multiple-testing haircut, costs, look-ahead and memorisation checks).

## Layout
- `config/sources.yaml` — data sources; one block per adapter (swap adapters here)
- `config/monitor.yaml` — alert thresholds
- `pmstack/` — adapters, store (Parquet + DuckDB), monitor, run log, CLI
- `data/obs/<source>/<year>.parquet`, `data/text/<source>.parquet` — research memory (numbers, policy text)
- `briefs/<date>/` — `facts.md`, `facts.json`, `alerts.json`, `note.md`
- `notes/` — research, calls, podcasts (markdown with YAML header); `notes/context.md` — standing facts Bernardo has stated (agents take them as given)
- `journal/<YYYY>/<id>.md` — decision journal (paper/example ideas only): conviction, payoff, invalidation, source, events, outcome; `pmstack/journal.py` runs the hard checks and stats
- `pmstack/sizing.py` — sizing assistant (agent 4): Kelly-relative units, cap, steps, drawdown cut (on the marked book since agent 8: open marks count), flags, review
- `pmstack/critic.py` + `config/critic.yaml` — critic (agent 5): card (outside view, reference class, tape, crowd, policy, alerts, Zweig triggers), slot plan, save/answer/withdraw/outcome, Friday `weekly`, `stats`. Code picks the questions; the model only words them; saved questions are frozen
- `pmstack/review.py` + `config/review.yaml` — weekly review (agent 6): process scorecard (process first, leaks, outcomes gated by sample size with intervals and shrinkage), goal catalogue and tracking (`journal/goals.yaml`), monthly section. Review week = 7 days ending 18:00 BRT Friday
- `pmstack/consensus.py` + `config/monitor.yaml` (`consensus:`) — consensus and narrative monitor (agent 7): GDELT attention stages for 18 frozen narratives (+1 validation query), trend-follower proxy (1/3/12-month vote, strength, flip levels), CFTC percentile beside it, labels and idea placement (all inference), Fed wording counts; `narrative_spreading` alert vs the previous pack. Descriptive only, every narrative "unvalidated" until GPR/EPU + headline audit
- `pmstack/risk.py` + `config/risk.yaml` — risk and crowding (agent 8): risk model (EWMA vol; calm and stress correlation, Ledoit–Wolf), risk table in R, effective independent ideas, clusters, stress P&L in R (replays, named driver shocks, worst case at k = 3; stops honoured and gapped), CTA levels, crowding per idea (red only when funding stresses), one marked book curve for amber and red warnings. Since v2 (10 Oct evening) stress runs on history back to 1986 (`risk.history`: futures from ~2000, spot/index/yield proxies before, roll screen): a 32-episode library replayed day by day, the worst 1/5/20/60-day windows for today's book, named shocks under stress/2008/2022 correlations. `risk.marked_drawdown` is also the sizing assistant's drawdown cut (open marks count). Only realised signals alert; nothing after the as-of date is used
- `pmstack/fetch.py` — `history_start` (prices, FRED: 1986) = one-time deep fetch per series, marked in `data/obs/<source>/_history.json`; a `--backfill` goes back to it too
- `pmstack/adapters/gdelt.py` — GDELT DOC 2.0 (free, keyless; cite "The GDELT Project" with a link). Unreachable from the cloud sandbox: runs in GitHub Actions only, with a 12-minute budget and 30–60 s backoff on HTTP 429; missing series are fetched first and catch up next run. Queries are frozen: an edit gets a new `_vN` id
- `pmstack/discovery.py` + `pmstack/adapters/gdelt_disc.py` + `config/discovery.yaml` (+ `config/sources.d/discovery.yaml`) — narrative discovery (agent 7, step 1 of 2; 20 Oct 2026): English GKG page-title words and word pairs counted once per source domain in BigQuery (~0.35 GB a day, shared byte ledger), day aggregates in `data/narratives/discovery/days/` (gitignored: kept in the data job's Actions cache, rebuilt by the backfill if evicted), each day scored vs its own trailing history (EWMA share z with a noise floor; day-1 "new" flag), candidates written once per day to `data/narratives/discovery/candidates/` and usable from the next day; "Narrative discovery" section in facts.md with point-in-time price and CFTC co-movement context. Step 2 is Bernardo's selection: `.claude/skills/narratives/` + `/narratives review` (promote / watch / dismiss, `decisions.jsonl`); promotion = draft query, `narratives measure`, headline audit (>= 70% precision), then a frozen definition in the Consensus map
- `docs/project/` — project hand-off docs (plan and status `agents-plan.md`, kickoff briefs, session notes `notes-A<n>.md`). Source of truth since 15 Oct 2026; start any new build session from `docs/project/agent-build-kickoff.md`
- `pmstack/adapters/gdelt_bq.py` — GDELT GKG via BigQuery (secrets `GCP_SA_KEY` JSON + `GCP_PROJECT_ID`, read from env only; Actions only): the same frozen queries matched on each article's title or URL path → `gdeltbqt:<qid>:count|share|tone`, `gdeltbqt:norm` (`gdeltbq:*` = URL path only, 15 Oct, kept, not updated); top headline links (title, source, URL, date only) → `data/text/gdelt_headlines.parquet`. Dry run + `maximum_bytes_billed` on every query; caps per query/run/month (sandbox: 1 TiB free) in `data/obs/gdelt_bq/_bytes.json`. consensus.py prefers it per narrative once its history is long enough (`consensus.instruments`), never mixing instruments. Block `gdelt_bq_v2` (series `gdeltbq2:*`, first in the order since 16 Oct) holds frozen v2 definitions per narrative (`narrative:` key; title words plus `theme:NAME` GKG themes), chosen by `python -m pmstack narratives measure` (manual workflow `narratives-measure.yml`; results in `docs/research/narrative-measure/`)
- `data/narratives/tracker.json` — narrative tracker: stage, since when, every change with its headlines; `python -m pmstack narratives tracker|headlines <id>|audit <id>|audit-score <id>` (audit sheets in `docs/research/narrative-audit/`)
- `pmstack/audit.py` — number auditor: every figure, date and alert ref in an output checked against `facts.json`/`facts.md`/journal; `--flag` writes the banner
- `pmstack/digest.py` + `config/digest.yaml` — research digester (agent 10): transcript capture (YouTube captions, files, PDFs; full text kept in `data/transcripts/`, gitignored), claim cards checked by code (quote found, numbers in the quote, imported names, hedges, deadlines, stated levels vs stored close, [ASR?]), `<note>.cards.json` beside each note, code facts `<note>.facts.json`, call ledger scored on stored prices as of a date, speaker records (weight from 15 resolved calls), `notes/index.md`, critic hook (`notes.*` facts), journal source-ref guard. Skill `.claude/skills/digest/` + `/digest`
- `pmstack/network.py` + `config/network.yaml` — network and reputation (agent 11): contacts and call notes in a **separate private repo** (`../pm-network`, or `PM_NETWORK_HOME`) — never in this repo or the run log; only `contacts.yaml` holds names, calls use ids. Call notes need the MNPI attestation; follow-ups, second touch, cadence by layer, dormant reconnects, monthly metrics, prep, forget, compliance log. Public commodity post (`notes/public/`): pack and chart from public-domain series only (FRED/EIA/CFTC, never Yahoo), recorded calls, scorecard, post checks. Skill `.claude/skills/network/` + `/network`
- `pmstack/balance.py` + `config/balance.yaml` — balance keeper (agent 9): oil stocks vs the same week of the prior five years (EIA convention: level, range, z, change vs the 5-year change, days of supply, 4-week implied demand, adjustment flag), WASDE as first published (US stocks-to-use, revision vs the previous report beside USDA's own average miss, old crop beside new, world and world ex-China), PSD histories (stocks-to-use percentile since 2007/08, world sugar), NASS crop condition and quarterly stocks. "Balances" section in the fact pack, `bal.*` critic facts, a few dated alerts. Every number used from its availability date (`available_lag_days`). Descriptive only, never "vs consensus". Skill `.claude/skills/balance/` + `/balance`
- `config/sources.d/*.yaml` — an agent's own source blocks, merged into `config/sources.yaml` by `fetch.py` (agent 9: `eia_bal`, `wasde`, `usda_psd`, `nass`; keys `USDA_FAS_API_KEY`, `NASS_API_KEY` from env). Offline tests skip them (`PMSTACK_NO_SOURCES_D`, set in tests/conftest.py)
- `pmstack/evals.py` + `evals/` — own test set: 20 frozen tasks with known answers (`tasks.yaml`, gold in `gold.yaml`, fixtures in `evals/fixtures/`, 5 sealed), graded by code; runs in `evals/runs/<date>-<label>/` (k = 3, pass^3, Wilson, paired vs a baseline); digester quote-check calibration (`evals/cards/`) and re-digest noise. **Run it before any agent, skill, prompt or model change**; a task that newly fails blocks the change until its answer is read. Answering sessions never open `evals/gold.yaml`, `tests/`, `evals/cards/` or other runs. Skill `.claude/skills/evals/` + `/evals`
- `pmstack/research.py` + `config/research.yaml` + `research/` — research loop (agent 12): studies registered in `research/studies/<id>.yaml` (frozen by hash in `research/ledger.jsonl`; an edit is a new id; a recall probe written before the run), flags recomputed point in time with the agents' own functions on a weekly grid, base rate and lift on independent episodes, circular-shift placebo (one calendar shift for all sources), BH q ≤ 10% across every registered flag study (missing or insufficient ones count with p = 1), definition hash (config + code) frozen at the first run, narrative-based flags "in-sample only" until live episodes agree (their queries were written with the history in view), CFTC flags dated at the release (Monday in holiday weeks), halves and drop-one-year, shrunk and decay-haircut effects; strategies (TSMOM) vs the long-only and historical-mean books after the AQR cost table, deflated Sharpe over every variant, post-publication apart. Results `research/results/<id>.md|json`, `research/index.md` (verdicts + graveyard, never pruned), `research/verdicts.json` (read by the Risk section and the critic card). `pmstack/qstats.py` = the quant-research-standards statistics. Skill `.claude/skills/research/` + `/research`. Only a `supported` flag may alert, and still as context
- `docs/research/` — literature review behind each agent (risk.md for agent 8, balance.md for 9, digester.md for 10, network.md for 11, test-set.md for the own test set, research-loop.md for 12)
- `skills/morning-note/` — the 06:18 BRT note (v2: journal-first, audited); `skills/critic-weekly/` — the Friday 18:17 BRT review (critic pass + scorecard + one goal); `.claude/skills/journal/` + `/journal` command — 60-second idea capture, then the critic's card and questions
- `logs/runs.jsonl` — audit trail

## Parallel sessions (decided 20 Oct 2026)
- **One checkout per session.** Two Claude sessions never work in the same folder: a branch switch, merge or rebase in one changes the files under the other (this happened on 19–20 Oct). The main checkout `C:\Users\user\code\pm-agent-stack` belongs to one session at a time; every other session works in its own git worktree:
  `git worktree add ../pm-agent-stack-<task> -b <task-branch> origin/main`
  (from the Desktop app, start the session with "use a worktree"). Remove it when merged: `git worktree remove ../pm-agent-stack-<task>`.
- **Python:** a worktree has no `.venv`; use the main checkout's: `..\pm-agent-stack\.venv\Scripts\python -m pytest -q` (run from the worktree folder so `pmstack` is imported from it).
- **Merging:** `git pull --rebase origin main` and the full test suite in the worktree, then fast-forward `main` (`git push origin <task-branch>:main`). `logs/runs.jsonl` conflicts are resolved as the union of both sides ordered by `ts`.
- File ownership between tracks (see `docs/project/notes-and-keys-kickoff.md`) still applies inside worktrees.

## Commands
```
python -m pmstack all              # fetch every source, then build today's fact pack
python -m pmstack fetch --only eia # one source
python -m pmstack monitor --date 2026-10-05
python -m pmstack journal new|event|close|reject|list|stats|book|check   # decision journal (close needs --trigger)
python -m pmstack journal size <id> | sizing-review                     # sizing assistant
python -m pmstack critic card <id> | save <id> --json '[...]' | answer <id> --q q1 ... | weekly --write | stats   # critic
python -m pmstack review weekly [--date D] [--write] [--monthly] | goal show|set <key>|drop|list   # weekly review
python -m pmstack risk [--date D] [--out file.md]   # risk and crowding stress report (agent 8)
python -m pmstack audit briefs/<date>/note.md [--facts extra.json ...] [--flag]   # number auditor
python -m pmstack narratives tracker [--changed-since D] | headlines <id> | audit <id> | audit-score <id>   # narrative tracker
python -m pmstack discovery list [--date D] | show <id> | decide <id> --action promote|watch|dismiss [--reason ...] | placebo | draft <id>   # agent 7 discovery
python -m pmstack digest fetch <link|file> | chunks <sha> --window N | save <note> --cards c.json --transcript <sha> | facts <note> --write | index | calls [--date] | view --market BZ=F | diff <note>   # agent 10
python -m pmstack network init | contact add --set k=v ... | call new --json f | due | reconnect | prep <id> | monthly --write | forget <id> --yes | public pack --market BZ=F | public add-call --json f | public score | public check <post>   # agent 11
python -m pmstack balance [show|probe] [--date D] [--out f]   # agent 9: the Balances section on demand / what the new sources returned
python -m pmstack evals list | prompt <id> --run <dir> | new-run <label> --model <id> | grade <dir> [--no-log] | report <new runs> --versus <base runs> | calibrate | noise   # own test set
python -m pmstack research flags | list | new <spec.yaml> | run <id>|--all [--date D] | index | show <id>   # research loop (agent 12)
python -m pytest -q                # offline tests (test files are read and written as UTF-8, so Windows needs no PYTHONUTF8 since 20 Oct)
```
Query the memory: `python -c "from pmstack import store; print(store.connect().execute('select source, count(*) from obs group by 1').df())"`
