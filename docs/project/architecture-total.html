PM Agent Stack Architecture

The proposal merges the 12-agent roster with the three pillars from the specialists brief (Donnelly's "Trade Outside the Box"). Read the diagram from the bottom up. Code fetches and computes, and only code writes to memory. The three pillars read memory and return cards. The cards feed the notes and the decision loop, and Bernardo decides.

Agent 12 becomes "Research", the fundamentals pillar. /ask reaches the orchestrator, the read-only specialists and the generalist. The existing research loop becomes the pillar's testing gate (/research, unchanged). Every driver estimate and every flag from any pillar passes through it before it may alert.

Rules the shape enforces

  • Code computes and the model writes. Agents explain and flag, and code computes every signal. Results are evaluated forward only.
  • Specialists are read-only. One orchestrator verifies their work, and only code functions with provenance write to memory.
  • Agents never debate freely. Independent views are averaged, and the critic stays the targeted challenger.
  • At most two layers: generalist over specialists. A Commodities layer comes only when the merge rule holds (test sets pass, the index fits, and cross-commodity questions are frequent).
  • No knowledge in prompts. It lives in knowledge/ by commodity, so routing changes without a rebuild.
  • Every driver size is labelled literature, own estimate or Bernardo prior. When an estimate and a prior disagree, the gap becomes an open question.
  • Personal build only: no fund data, no broker research, no Bloomberg data.
